# Kampanya Radarı: published files

This repository holds only what the Kampanya Radarı app reads from the web:

- `feed.json`: the day's card and store campaigns with their terms
- `gizlilik.html`: the privacy policy
- `index.html`: the support page

They are served at https://malimkalyoncu-lab.github.io/kampanya-radari/ and rebuilt every morning by an automated job, which replaces the whole repository. Changes made here directly are overwritten.
